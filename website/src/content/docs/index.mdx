## Trust your data, prove it to everyone

AeternisLog implements the **Tamper-Evident Data Anchoring** pattern: your records
live in a fast, queryable database, are grouped into **Merkle trees**, and the
root of each batch is written **once** to **Hyperledger Fabric**. Any later
tampering is mathematically detectable — recompute the root and compare it to the
chain.

<CardGrid>
  <Card title="Tamper-evident by math" icon="approve-check">
    Every record is hashed with a length-prefixed, domain-separated SHA-256 scheme
    and folded into a Merkle tree. Change one byte and the root no longer matches
    the chain.
  </Card>
  <Card title="Anchored on a blockchain" icon="star">
    Merkle roots are anchored **write-once** on a permissioned Hyperledger Fabric
    ledger — no one, not even an admin, can rewrite an anchored root.
  </Card>
  <Card title="Multi-tenant isolation" icon="puzzle">
    Records are isolated per tenant and domain, and isolation is enforced at the
    **ledger boundary** by the caller's signed identity — not a string prefix.
  </Card>
  <Card title="Drop-in SDKs" icon="open-book">
    Go and Python SDKs recompute hashes and Merkle roots **locally**, so integrity
    can be verified without trusting the server.
  </Card>
</CardGrid>

## How it works

```
POST /api/v1/{domain}/records ─▶ MongoDB ─▶ Merkle batch ─▶ anchored on Fabric
                                                              │
        auditor recomputes the root ◀─────────────────────────┘  match? ✓ / ✗
```

An auditor (or your own SDK) recomputes the Merkle root from the stored records
and compares it against the immutable root on the blockchain. They match only if
nothing was altered.
